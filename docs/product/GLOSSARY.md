# Glossary — coined terms

On-screen names always win; a term lives here only when the screen offers
none. Each term has this one definition home — specs gloss or link on first
use (TEMPLATE rule 10). Cross-app vocabulary is `APP-GLOSSARY.md`'s job.

<a id="deciding-editor"></a>
## deciding editor

A user the server allows to record editorial decisions on a submission's
current stage: a participant holding an editor role (Journal Editor, Section
Editor, Guest Editor, or a Journal Manager assigned to the submission) whose
stage assignment does **not** have "Recommend only" checked — or, when the
submission has no such assignee for the viewer, a Journal Manager or Site
Administrator acting without an assignment. The screens never name this
condition; they simply show or withhold the decision buttons and the
"Recommendation" listing. Counterpart: a *recommend-only participant* (an
on-screen concept — the "Recommend only" checkbox on a stage assignment)
records recommendations instead.

First used by: `specs/review-stage-and-rounds.md`.
